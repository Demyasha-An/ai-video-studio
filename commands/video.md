# ВИДЕОПРОИЗВОДСТВО — выполняется в этой (главной) сессии

## ❗ КРИТИЧЕСКОЕ ПРАВИЛО ДЕЛЕГИРОВАНИЯ

**Выполняй этот конвейер САМ, в текущей сессии. Ты — режиссёр-координатор на этой сессии.**

- **ЗАПРЕЩЕНО** вызывать `Agent(video-director)` и вообще передавать конвейер целиком кому-либо. Субагенты ZCode не могут порождать субагентов — конвейер, отданный субагенту, деградирует в fallback.
- **ЕДИНСТВЕННОЕ разрешённое использование Agent tool** — запуск РОЛЕВЫХ субагентов на конкретные этапы: `video-scriptwriter`, `voice-producer`, `motion-designer`, `video-editor`, `video-quality-controller`.
- Каждый вызов Agent = один этап с конкретным заданием и ожидаемым артефактом (файл/рендер/отчёт). Независимые вызовы делай параллельно в одном сообщении.

Задача пользователя: $ARGUMENTS

## Конвейер (этап выполняешь сам → роль отправляешь субагенту → проверяешь результат)

1. **Брифинг** (сам): тема, платформа (по умолчанию Reels/Shorts/TikTok 1080×1920@30), длительность (по умолчанию 30–60 c). Неясное — ОДИН уточняющий вопрос, не блокируя старт.
2. **Сценарий** → Agent(video-scriptwriter): таймкоды, раскадровка, текст озвучки, CTA → `{{STUDIO_DIR}}\scripts\<slug>.md`. Проверь сам: хук в 1–3 с, темп 2.2–2.6 слова/с, нет выдуманных фактов (плейсхолдер `{{ФАКТ: уточнить}}`).
3. **Референсы** (сам; skills `video-style-reference`, `modern-motion-reference`): 3–5 анимаций из `{{STUDIO_DIR}}\video-reference-library\catalog.json` (142 позиции; `node tools/search.mjs`, для финансов/аналитики — категории financial/dataviz/ainfo/amaps + `modern:true`). Пользователь просил показать — дай ID + превью (галерея: `python -m http.server 4173 --bind 127.0.0.1` из каталога библиотеки → http://127.0.0.1:4173/gallery/index.html) и жди выбора. Не просил — выбери сам (`commercial:true` приоритет) и зафиксируй. `commercial:"verify"` — только анализ приёмов, без копирования кода.
4. **Озвучка** → Agent(voice-producer): edge-tts блоками с ретраями (NoAudioReceived — до 10 попыток, sleep 3–5с, fallback голос), `loudnorm` −14 LUFS, таблица фактических таймингов. ElevenLabs — только если подключён и разрешён.
5. **Анимация** → Agent(motion-designer): передай список ID референсов + `code_path` + тайминги озвучки. Готовые порты — `compositions/src/lib/library/`. Напомни ему: внутри Sequence использовать ЛОКАЛЬНЫЕ кадры (BEATS − from сцены), рендер в `renders/`.
6. **Монтаж** → Agent(video-editor): сборка → `output/<slug>.mp4` (H.264 CRF 19, AAC 192k, `+faststart`).
7. **QC** → Agent(video-quality-controller): полный чеклист → отчёт в `reports/<slug>-qc.md`.
8. **Цикл исправлений**: FAIL → возврат конкретному субагенту с пунктами → повторный QC. Максимум 3 цикла.
9. **Сдача**: путь к файлу, QC-вердикт, использованные референсы (ID), что доработать.

## Правила
- Факты — подтверждённые (с источником) или плейсхолдер. Музыка/фото/видео — лицензированные или созданные студией.
- Не плати сам; платное (ElevenLabs и т.п.) — запросить у пользователя.
- Прогресс — TodoWrite; артефакты — в своих каталогах (`scripts/`, `audio/`, `renders/`, `subtitles/`, `reports/`, `output/`).
- Если Agent tool недоступен в сессии — выполняй роли сам по инструкциям `~/.zcode/agents/*.md` и отметь «fallback» в отчёте.
