# FFmpeg 9: новый парсер filtergraph — грабли и обходы

FFmpeg 9.0 переписал парсер filtergraph. Старые канонические приёмы (drawtext + expressions + Windows-пути) перестали работать. Здесь — все найденные проблемы и рабочие обходы (проверены на 9.0.1, Windows).

## Симптом → причина → обход

| # | Симптом | Причина | Обход |
|---|---|---|---|
| 1 | `No option name near '/Windows/Fonts/...'` | Кавычки `'...'` больше **не защищают `:`** внутри значения | Путь без двоеточий: скопировать шрифт в проект (`tools/fonts/arialbd.ttf`) и указать относительный путь |
| 2 | Сплит значения на первом `:` даже внутри кавычек | `\:` больше не экранирует двоеточие | Только убирать `:` из значений (пути/текст через файлы) |
| 3 | `\,` в выражениях — работает | — | Запятые в inline-выражениях экранировать как раньше: `min(a\,b)` |
| 4 | `Unrecognized option 'filter_complex_script'` | Опция удалена в 9.0 | Передавать граф инлайн `-filter_complex "$(cat graph.filter)"`; файл как аргумент не читается (`No such filter`) |
| 5 | drawtext с `%{eif:...}` — `No option name near 'trunc...'` | `%{...}` инлайн ломает парсер | Динамический текст — **только через `textfile=<файл>`**: содержимое файла парсер не видит, `%{eif:EXPR:d}` внутри работает свободно (двоеточия и запятые — без экранирования) |
| 6 | `Stray % near '%'` | `%%` больше не разворачивается в литеральный `%` | Литеральный процент в тексте — `\%` |
| 7 | drawtext не читает `/tmp/file.txt` | ffmpeg.exe не знает POSIX-пути MSYS | Только относительные или Windows-пути; относительные предпочтительнее (см. #1) |
| 8 | `fontfile=C\:/...` — сплит на `D:` | Двоеточие буквы диска = разделитель опций | Относительный путь (`tools/fonts/arial.ttf`) или POSIX-путь на Linux |

## Проверенные мини-пробы (воспроизводимость)

```bash
# OK: текст из файла, eif с чистыми двоеточиями
printf '%s' '%{eif:trunc(8000000*min(t/1.4,1)):d} ₽' > t.txt
ffmpeg -f lavfi -i color=c=black:s=400x80:d=0.2 \
  -vf "drawtext=fontfile=tools/arialbd.ttf:textfile=t.txt:fontcolor=white:fontsize=30" \
  -frames:v 1 out.png

# OK: литеральный процент
printf '%s' '−35\%' > t.txt

# FAIL (все варианты): инлайн 'text=%{eif:...}' с двоеточиями и запятыми — на любом экранировании
```

Все находки уже зашиты в `tools/draft-render.mjs` — генератор filtergraph'ов, которому можно доверять на FFmpeg 9.
