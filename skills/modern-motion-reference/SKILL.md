# Modern Motion Reference — современные референсы для ролика

Библиотека: `{{STUDIO_DIR}}\video-reference-library\` (catalog.json v2, 135 позиций; современные — фильтр `modern: true`, категории: ainfo, dataviz, financial, amaps, ktypo, editorial, explainer, minimalism, threed, uimotion, restatemotion, premiumsocial).
Галерея: `python -m http.server 4173 --bind 127.0.0.1` из каталога библиотеки → http://127.0.0.1:4173/gallery/index.html (быстрые фильтры: «Бесплатно», «Есть код», «Инфографика», «Современные референсы»).

## Конвейер работы (выполнять по шагам)

1. **Анализ темы**: определи жанр (финансы/образование/аналитика/реклама/недвижимость), ключевую сущность (цена, доля, сравнение, маршрут, процесс) и платформу (9:16/16:9).
2. **Поиск примеров** (5–10):
   ```bash
   cd {{STUDIO_DIR}}\video-reference-library
   node tools/search.mjs --cat financial          # категория
   node tools/search.mjs "скидка кольцо"          # ключевые слова (ищет и по style)
   node tools/search.mjs --ids OML-FINAN-001,VSL-FINAN-001
   ```
   Для финансов/аналитики приоритет: `financial`, `dataviz`, `ainfo`; для документов/разборов — `editorial`, `explainer`; для премиум-рилсов — `premiumsocial`, `minimalism`.
3. **Анализ каждого примера** (кратко, по полям записи): `style` (композиция, цвет, типографика, движение) и `timing` (темп и ритм появления). Поля заполнены для современных референсов.
4. **3–5 визуальных концепций** для сценария пользователя: для каждой — какие референсы лягут в основу (ID), что возьмём (приём композиции/движения), и как адаптируем под данные ролика. **Не копировать чужие ролики и кадры** — только анализ и самостоятельное воспроизведение приёмов.
5. **Показ превью**: дай прямые ссылки на демо (`gallery/demos/demo-player.html?id=<ID>`) или открой галерею с нужным фильтром. Ждём выбора по ID (или selection.json из галереи).
6. **Передача Motion Designer**: список ID + `code_path` (если `has_code: true` — можно адаптировать MIT-код) + выдержки style/timing + данные сцены.
7. **Реализация в Remotion**: готовые порты уже в `compositions/src/lib/library/` (price-compare-bars, discount-ring, number-punch, minimal-price-card, restate-price-reveal, premium-social-frame + базовые VSL-*). Остальное Motion Designer портирует по демо/коду.

## Лицензии (кратко)

- **MIT / CC0** (`commercial: true`) — код/видео/промпты можно использовать в коммерческих роликах: opus, rendercomp, rve, studio, aicss (free-работы).
- **verify** — только анализ и самостоятельное воспроизведение, без копирования материалов: artiphik (чужие YouTube-ролики), lottie (лицензия по элементу), animode, kisto, ali, skillry.
- Правило: референс = источник приёма, не материал для вставки.
